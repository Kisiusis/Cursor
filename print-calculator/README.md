# Калькулятор печати

Готовый файл для Windows лежит в этой же папке: [PrintCalculator.exe](PrintCalculator.exe). На странице файла на GitHub кнопка Download (или Raw) скачивает его.

Окно называется «Калькулятор печати». `index.html` внутри exe не менялся: те же стили, разметка и расчёт. Настройки материалов и цена резки пишутся в localStorage и сохраняются между запусками.

Это portable-сборка для 64-битной Windows: двойной щелчок распаковывает приложение в профиль пользователя и открывает калькулятор. Отдельная установка не нужна. Файл не подписан, поэтому SmartScreen при первом запуске может спросить подтверждение.

## Сборка Windows exe

`PrintCalculator.exe` уже собран. Команды ниже нужны только если файл собирается заново.

Нужны Node.js 22 и интернет (скачивается Electron для Windows).

```bash
cd print-calculator
npm install
npm run build:win
```

После сборки тот же файл появляется как `print-calculator/dist/Калькулятор-печати.exe`. В репозиторий он копируется под именем `PrintCalculator.exe`.

Проверка интерфейса и формул без сборки exe:

```bash
npm run verify
```
